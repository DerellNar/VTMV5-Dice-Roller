# VTMV5 Dice Roller Plugin for Obsidian

VTMV5 Dice Roller is a plugin for [Obsidian](https://obsidian.md) that provides dice rolling functionality for [Vampire: The Masquerade V5](https://vtm.paradoxwikis.com/VTM_Wiki) TTRPG.
Useful for Storytellers and Players who want to organise their sessions in [Obsidian](https://obsidian.md).

## Description

The plugin adds a ribbon icon, which opens a workspace view on the Right Panel, where you can use the Dice Roller.
The view can also be opened by the command "Open VTMV5 Dice Roller".
### Usage

1. Enter the total Dice Pool
2. Enter how many Hunger Points the Character has.
3. Press Roll.

In the Settings page you can select the Willpower Re-Roll strategy for the Roller to use:
Willpower allows you to Re-Roll up to 3 Dice.
- **Manual**: 
	- User selects all Regular Dice to Re-roll.
- **Maximise Crits**:
	- Automatically Re-rolls as many Dice as possible to maximise the chances of a critical
	- Will Re-Roll has many failed Dice as possible. And any number of non-crit successes.
- **Maximise Failed Dice Re-Roll**: 
	- Automatically Re-rolls the maximum failed dice. Only the failed Dice.
